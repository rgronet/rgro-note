## 폴더

    알지로노트/            ← 내려받은(또는 올린) 노트 프로그램 폴더
      public/              ← 웹루트 (도메인 문서 루트를 여기로)
        index.php          화면 (로그인 / 3단 노트 화면, 모바일은 한 화면씩)
        api.php            노트 JSON API (POST 는 CSRF 헤더 필수)
        file.php           첨부 내려주기 (로그인 확인 후)
        login.php, *_callback.php, password.php, logout.php   로그인(아이디·암호/구글/네이버/카카오)
        assets/            app.js(화면), editor.js(에디터 어댑터), app.css, icon.svg
        assets/vendor/     Toast UI Editor 3.2.2, marked, DOMPurify (외부 CDN 안 씀)
      app/                 ← 웹루트 밖
        config.php         설정 (로그인 방식, 허용 계정 → 사용자 폴더, 소셜 로그인 키)
        lib/               Store(저장), Auth(로그인 방식·계정·암호), GoogleAuth, Enml(에버노트 변환)
        tools/import_enex.php   에버노트 가져오기 (CLI, 한 번만)
      data/                ← 웹루트 밖, 쓰기 권한 필요
        sessions/          로그인 세션 (30일 유지)
        users/u1/
          index.json       노트북·태그·날짜·휴지통 등 메타 (+ index.json.bak)
          notes/<ID>.txt   노트 원본
          files/<ID>/      첨부

txt 가 원본입니다. FTP 로 `notes/` 에 txt 를 넣거나 고치면 다음 접속 때 자동으로 목록에 반영된다.
index.json 이 깨지면 .bak 을 쓰고, 둘 다 없으면 txt 에서 다시 만든다(노트북·태그는 잃음).

## 설치

자세한 것은 [INSTALL.md](INSTALL.md). 요약:

1. 서버에 폴더 통째로 올리고, 도메인 문서 루트를 `public/` 으로 지정(문서 루트가 `www` 로 고정된 호스팅은 INSTALL 참고)
2. `data/` 폴더에 PHP 쓰기 권한 (예: 707 또는 웹서버 사용자 소유)
3. `app/config.sample.php` → `app/config.php` 로 복사하고 로그인 방식·허용 계정을 적는다
   - **아이디·암호**(기본): 계정에 `login_id` 와 처음 암호만 적으면 된다. 처음 로그인 때 새 암호로 바꾼다.
   - **구글 · 카카오 · 네이버**: 쓰는 것만 `'login'` 에서 켜고, 각 개발자 사이트에 앱을 등록해 받은 키를 넣는다.
     돌아올 주소는 `https://내도메인/google_callback.php` · `kakao_callback.php` · `naver_callback.php`
4. HTTPS 필수 (세션 쿠키 Secure, 소셜 로그인)
5. PHP 확장: mbstring, zip, dom·xmlreader·simplexml (에버노트 가져오기), curl 또는 allow_url_fopen (소셜 로그인)

## 에버노트 가져오기 (한 번만)

1. 에버노트 데스크톱 앱에서 노트북마다 우클릭 > 내보내기 > ENEX(.enex) 로 저장
   - 파일 이름이 노트북 이름이 된다. 에버노트가 붙이는 " (3368개 노트)" 는 뺀다
2. 실행

       php app/tools/import_enex.php u1 D:/evernote_export

   - 서버에 SSH 가 없으면 PC 에서 돌린 뒤 `data/users/u1/` 를 FTP 로 올린다.
   - 다시 돌려도 이미 가져온 노트는 건너뛴다.
   - 변환 규칙을 고친 뒤에는 `--refresh` 를 붙여 다시 돌리면 이미 가져온 노트를 새 규칙으로 다시 쓴다
     (노트 ID·첨부·날짜 유지, 가져온 뒤 웹에서 고친 노트는 건드리지 않음).

         php app/tools/import_enex.php --refresh u1 D:/evernote_export
3. 변환 규칙: 에버노트에서도 "제목 없음·제목 없는 노트"인 노트는 본문 첫 줄을 제목으로(짧으면 본문에서 옮기고, 길면 50자까지), 글이 없으면 "메모 날짜". 본문 → Markdown(에버노트 한 줄 = 한 줄), 체크박스 → `- [ ]`, 이미지·첨부 → `files/`, 표 → Markdown 표,
   코드 블록 → ``` , 암호화 텍스트는 "[암호화된 내용]" 으로 표시, 노트 사이 링크(evernote:///)는 그대로 남음(열리지 않음).

## 본문 형식과 에디터

- 노트를 열면 **위지윅 탭** 이 기본. 위지윅 탭은 Toast UI Editor. 저장은 Markdown.
- 소스 탭에서 쓴 글은 에디터가 다시 정리하지 않고 그대로 저장된다.
- **한 줄 = 한 문단.** Toast UI 는 줄바꿈 하나를 새 문단으로 보여 준다.
  빈 줄은 빈 문단으로 보인다. 목록·표·제목·코드 블록 앞뒤에만 빈 줄을 둔다.
- 첨부·이미지 주소는 `file.php?n=노트ID&f=파일명` (상대 주소).
- 노트를 열기만 하면 내용은 바뀌지 않는다. 본문을 고쳐 저장할 때 에디터 방식으로 다시 쓴다.
  목록 기호 `-` 가 `*` 로, 하위 목록 들여쓰기가 4칸으로 바뀔 수 있다(내용은 같음).
- 에디터를 바꿀 때는 `assets/editor.js` 만 고치면 된다.

## 백업 · 복원 (사이드바 아래 "백업·복원")

- **백업 받기**: 노트·첨부·노트북·태그·날짜 전체를 zip 하나로 내려받는다.
- **zip 으로 복원**: 지금 데이터를 zip 내용으로 **통째로 바꾼다.**
  - 4MB 씩 나눠 올리므로 호스팅 업로드 크기 제한에 걸리지 않는다.
  - 서버에서 임시 폴더에 다 푼 뒤 한 번에 바꿔치기한다. 중간에 실패하면 지금 데이터는 그대로.
  - 바꾸기 전 데이터는 `data/users/.before-restore-u1-날짜` 로 최근 3개까지 서버에 남는다.
  - 받을 수 있는 zip: 이 화면에서 받은 백업, 또는 PC 의 `data/users/u1` 폴더를 압축한 것
    (맨 위 폴더 이름은 상관없음, 윈도우 기본 압축의 한글 이름(CP949)도 됨).
  - 정해진 파일(index.json, notes/*.txt, files/ID/이름)만 풀고 나머지(.lock, 등 경로 밖으로 나가는 이름)는 버린다.
- 서버 PHP 에 zip 확장(ZipArchive)이 있어야 한다.

## 동작

- 열면 바로 편집, 자동 저장(1초), 다른 기기에서 먼저 고친 노트를 저장하면 덮어쓰지 않고 "(충돌 사본)" 새 노트로 저장
- 다른 탭/앱으로 갔다 오면 최신 목록을 다시 읽음
- 체크박스는 편집 화면에서 바로 체크
- 첨부: 툴바의 📎(모든 파일)·그림 버튼, 이미지 붙여넣기·끌어다 놓기. 최대 20MB (`upload_max_mb`, `.user.ini`)
- 휴지통 → 복원 / 영구 삭제
- 목록은 처음에 50개만 그리고, 아래로 스크롤하면 50개씩 이어 붙인다(노트가 수천 개라도 빠름)
- 화면 배치(PC): 편집 화면 위 버튼 ▥ 목록 왼쪽·내용 오른쪽 / ▤ 목록 위·내용 아래 / ⛶ 내용 전체보기. 브라우저마다 기억
- ⛶ 내용 전체보기에서는 "← 이전화면" 버튼(또는 Esc)으로 원래 배치로 돌아간다
- 목록에서 노트를 더블클릭하면 그 노트만 새 창에서 전체화면으로 편집한다(창에는 "닫기"만). 새 창 크기·위치는 기억해서 다음에도 그대로 연다.
  새 창에서 저장하면 원래 창의 목록·내용도 바로 바뀐다
- 태그: 노트 제목 아래 최근 쓴 태그 10개가 나오고 눌러서 넣고 뺀다. "…" 을 누르면 전체 태그를 찾아서 고를 수 있고 태그를 추가 할 수 있다
- 노트북 옮기기: 편집 화면 오른쪽 위 ⋯ 메뉴 > 노트북, 마우스 드래그앤 드랍으로 이동 가능하다
- 고정(📌): 사이드바 "고정"에 모아 보기. 목록 위로 에 먼저 표시된다.
- 즐겨찾기(★): 사이드바 "즐겨찾기"에 모아 보기. 목록 위로 올리지는 않는다.
- FTP 로 올려 파일 수정 시각이 바뀌어도 내용이 같으면 날짜를 바꾸지 않는다. 아직 안 올라온 txt 는 지우지 않고 숨긴다
- 노트 파일 확인(FTP 로 바뀐 txt 반영)은 목록을 불러올 때 5분에 한 번만 한다(노트가 많아도 빠르게). 시각은 `data/users/<사용자>/.reconciled`
- 검색은 노트 본문을 모아 둔 `data/users/<사용자>/search.cache` 한 파일만 읽는다. 바뀐 노트만 그때그때 다시 채우고, 지워도 다음 검색 때 다시 만든다
- 모바일: 홈 화면에 추가하면 앱처럼 열림 (아래 "안드로이드 앱")

## 안드로이드 앱 (웹 앱, PWA)

따로 만든 안드로이드 앱(apk)은 없다. 크롬이 이 사이트를 "앱으로 설치"하는 웹 앱(PWA) 방식이다.
설치하면 홈 화면 아이콘·앱 목록에 "알지로 노트"로 들어가고, 주소창 없는 앱 화면으로 열린다. 화면·기능은 웹과 같은 코드.

- 설치: 안드로이드 크롬에서 사이트 열기 → 오른쪽 위 ⋮ → **앱 설치** (또는 **홈 화면에 추가**)
- 관련 파일
  - `public/manifest.webmanifest` : 앱 이름(`short_name` = 홈 화면 이름), 아이콘, 시작 주소, 색
  - `public/assets/icon-192.png`, `icon-512.png`, `icon-maskable-512.png` : 앱 아이콘
  - `public/index.php` 머리 부분 : manifest 연결, 테마 색, 아이폰용 아이콘·이름
- 이름·아이콘을 바꾼 뒤에는 홈 화면 앱을 지우고 다시 설치해야 바로 반영된다(그냥 두면 크롬이 며칠 안에 알아서 바꿈)
- 진짜 apk 가 꼭 필요하면 이 웹 앱을 감싸는 방식(TWA, Bubblewrap)으로 만들 수 있다. 플레이 스토어에 올릴 때 필요

## 윈도우 실행 파일(exe)

**내려받기: [Releases](https://github.com/rgronet/rgro-note/releases/latest)** — `RgroNote.exe`, `note.ini.sample`, 로컬 모드 zip.
(실행 파일 소스는 공개하지 않는다)

크롬(없으면 엣지)을 주소창 없는 "앱 창"으로 열어 노트 사이트를 띄우는 작은 실행 파일이다.
진짜 브라우저라서 아이디·암호는 물론 구글·카카오·네이버 로그인도 그대로 된다(앱 안에 넣은 브라우저는 구글이 로그인을 막는다).

- RgroNote.exe 를 아무 폴더에 두고 바탕화면·작업 표시줄에 바로 가기를 만들어 쓰면 된다.
- 처음 한 번 로그인(켠 방식: 아이디·암호, 구글, 카카오, 네이버). 이 앱 전용 브라우저 프로필(`%LOCALAPPDATA%\RgroNote\chrome`, 엣지는 `\browser`)이라 평소 브라우저와 섞이지 않고, 로그인·창 크기를 따로 기억한다.
- 주소 바꾸기: exe 옆에 `note.ini` 를 두고 `url=https://내도메인/` 처럼 한 줄. (명령줄 첫 인자로 주소를 줘도 됨)
- 새로 만든 exe 는 백신이 처음에 막을 수 있다. 그럴 때는 백신에서 이 파일을 허용한다.
- 바깥 링크(알지로넷 등)는 앱 창이 아니라 PC 기본 브라우저로 열린다(`rgronote:` 주소를 이 exe 에 연결해 둠).

### 로컬 모드 (서버 없이 이 PC 에서)

exe 옆 `note.ini` 에 `mode=local` 한 줄을 쓰면, PHP 내장 서버(`php -S 127.0.0.1:8765`)를 창 없이 띄우고 앱 창으로 연다.
앱 창을 모두 닫으면 PHP 도 같이 꺼진다. 다른 설정은 Releases 의 `note.ini.sample` 참고.

1. PHP 준비: https://windows.php.net/download 에서 "VS17 x64 Non Thread Safe" zip 을 받아 exe 옆 `php\` 폴더에 푼다
   (또는 `note.ini` 에 `php=C:\php\php.exe`). `php.ini-production` 을 `php.ini` 로 복사해 두면 좋다.
   필요한 확장모듈(mbstring·openssl·curl·zip·fileinfo)은 사용할수 있도록 설정 해준다.
2. 처음 실행하면 노트 폴더 쓰기를 확인하고 **아이디·암호를 정하는 창**을 띄운 뒤 `app\config.local.php` 를 만든다.
   암호는 PHP `password_hash` 로 `data\auth\u1.json` 에만 저장. 그 파일을 지우고 다시 실행하면 새 암호를 정한다.
3. 노트는 `data\` 폴더(또는 `note.ini` 의 `data=`)에 저장된다. **서버의 노트와는 따로**이고, 옮길 때는 "백업·복원"의 zip 으로.

- 포트가 쓰이고 있으면 다음 번호를 쓴다. 포트가 바뀌면 브라우저가 다른 사이트로 봐서 로그인을 다시 해야 한다.
- PHP 오류 기록: `%LOCALAPPDATA%\RgroNote\php-local.log`
- **PHP 까지 들어 있는 zip**: [Releases](https://github.com/rgronet/rgro-note/releases/latest) 의 로컬 모드 zip 을 풀고 RgroNote.exe 만 실행하면 된다(PHP 따로 설치 필요 없음). PHP 는 Visual C++ 재배포 패키지(x64)가 필요하며, 없으면 실행기가 받을 곳을 안내한다.
- 윈도우의 PHP 내장 서버는 요청을 하나씩 처리한다. 혼자 쓰기에는 충분하지만 큰 백업·가져오기 중에는 다른 동작이 잠깐 기다린다.
